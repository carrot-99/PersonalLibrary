# 04. 画面設計

## 4.1 画面レイアウト

`client/Index.html` が唯一の HTML ページで、以下の領域で構成されます。

```
┌──────────┬──────────────────────────────────────────────────────────┐
│          │ にんじん図書館                 [通知エリア globalNotification]│
│ サイド    ├──────────────────────────────────────────┬───────────────┤
│ メニュー  │ サマリーパネル（6 項目）                  │ 最近追加した   │
│ (Navbar) ├──────────────────────────────────────────┤ 漫画           │
│          │                                          │ (作品名/巻数)  │
│ 登録      │ コンテンツ領域（tabContent）              │  最大 10 件    │
│ 検索      │   選択中の View を 1 つだけ表示            │               │
│ 一覧・管理│                                          │               │
└──────────┴──────────────────────────────────────────┴───────────────┘
```

| 領域 | 要素 ID / クラス | 内容 |
|---|---|---|
| メニュー開閉ボタン | `#menuToggle` | タブレット幅以下で表示。サイドメニューを開閉 |
| サイドメニュー | `#sideMenu` | `Navbar.html` を埋め込み |
| 検索欄 | `#globalSearchInput` | 作品名（datalist）で検索し、作品別検索（`TitleView`）を開いてその作品の所持状況を表示（`runGlobalSearch`）。完全一致、なければ部分一致が 1 件のときに確定。複数・0 件はエラー通知 |
| 通知エリア | `#globalNotification` | 成功（4 秒）・エラー（6 秒）で自動消去 |
| サマリーパネル | `.top-summary-panel` | 所蔵冊数 / 漫画所蔵冊数 / ラノベ所蔵冊数 / 登録作品数 / 登録Box数 / 最新登録（`getLibrarySummary`） |
| コンテンツ領域 | `#tabContent` | 各 View |
| 最近追加 | `#globalRecentLibraryTable` | 作品名・巻数（`getRecentLibrary`） |

サマリーパネルと最近追加は、**初期表示時とタブ切替のたびに再取得**されます。

### レスポンシブ

| 画面幅 | レイアウト |
|---|---|
| 1101px 以上（PC） | サイドメニュー常時表示、コンテンツと「最近追加」を横並び |
| 721〜1100px（タブレット） | ☰ ボタンでサイドメニュー開閉（外側の暗幕タップでも閉じる）、縦積み、サマリー 3 列 |
| 720px 以下（スマホ） | タッチ操作向けの専用レイアウト（下表） |

スマホ（720px 以下）の主な違い。スタイルは `Styles.html` 末尾の `@media (max-width: 720px)` にまとめ、他のルールより優先させています。

| 対象 | スマホでの表示 |
|---|---|
| 上部バー | タイトル・検索欄・通知エリアを画面上部に固定（スクロールしても表示）。検索欄は全幅。☰ は 48px |
| サイドメニュー | 幅は画面の 86%（最大 340px）、ボタン高さ 52px |
| サマリー | 3 列・2 段に圧縮 |
| 入力欄・ボタン | 文字 16px（iPhone の入力時ズームを防ぐ）、高さ 48px 以上。画面内の単独ボタン（[表示] [保存] [解析] 等）は全幅 |
| ツールバー | ボタンを横並び・等幅（高さ 52px） |
| テーブル | 文字を省略せず折り返し、列幅は内容に合わせる。シリーズ・作品・書籍の一覧では自動採番の ID 列を非表示（箱は BoxID を利用者が入力するため表示）。[編集]・ページングのボタンは 44〜48px |
| インライン編集 | 入力欄の最小幅を確保し、はみ出す分は画面内で横スクロール。入力欄には列名をプレースホルダー表示 |
| 写真から登録 | チェック・ボタン類を拡大、作品追加フォームは 1 列。[登録確定] は画面下部に固定（`position: sticky`） |

## 4.2 メニュー構成（`client/Navbar.html`）

サイドメニューの先頭に **[📚 書籍] / [📺 アニメ] の切り替え**があり、選んだほうのメニューだけを表示します（下表の「モード」列）。

| モード | グループ | ボタン | 表示 View | 色 |
|---|---|---|---|---|
| 書籍 | 登録 | 写真で確認・登録 | `PhotoImportView` | 紫 |
| | | 欲しい巻リスト | `WishListView` | |
| | 検索 | シリーズ別検索 | `SeriesView` | 青 |
| | | 作品別検索 | `TitleView` | |
| | | 箱別検索 | `BoxView` | |
| | 一覧・管理 | シリーズ一覧 | `SeriesListView` | 緑 |
| | | 作品一覧 | `TitleListView` | |
| | | 箱一覧 | `BoxListView` | |
| | | 書籍一覧 | `LibraryListView` | |
| アニメ | 視聴・登録 | 視聴中の一覧 | `AnimeWatchingView` | ピンク |
| | | アニメ登録 | `AnimeEntryView` | |
| | 検索・一覧・管理 | シリーズ別検索 | `AnimeSeriesView` | |
| | | アニメ一覧 | `AnimeListView` | |

- ボタン押下で `showTab('<View>')` → `closeSidebar()`。
- モードを切り替えると、そのモードの最初の画面を開く（書籍: `PhotoImportView`、アニメ: `AnimeWatchingView`）。続けてメニューを選べるよう、切り替えではサイドメニューを閉じない。
- 書籍モードだけの表示: 上部バーの作品名検索、所蔵サマリー、最近追加した漫画。
- アニメモードだけの表示: アニメのサマリー（視聴済・視聴中・視聴中断・視聴予定の期数、登録作品数、視聴話数の合計）。アニメ画面で `getAnimeData` を取得するたびに更新（`renderAnimeGlobalSummary`）。
- **初期表示は前回のモードの最初の画面**（初回・保存できない環境では書籍の `PhotoImportView`）。モードはブラウザの `localStorage` に保存。

## 4.3 画面遷移

全画面がメニューから直接切り替わるフラットな構成で、画面間の遷移（ボタンによる別画面表示）はありません。

## 4.4 検索画面

3 画面とも同じ構成です：オートコンプリート入力 ＋ 「表示」ボタン ＋ 結果テーブル（結果 0 件時は非表示）。検索中はインラインローディングを表示します。

| 画面 | View / ファイル | 入力 | 結果列 | API |
|---|---|---|---|---|
| シリーズ表示 | `SeriesView` / `series/SeriesView.html` | シリーズ名 `#seriesSelectInput` | 作品名, 所持巻数, 所持巻（抜けを含む） | `getSeriesDetail` |
| 作品表示 | `TitleView` / `title/TitleView.html` | 作品名 `#titleViewSelectInput` | 所持状況（下記）＋ 巻, BoxID（巻数順） | `getTitleDetail` |
| Box 表示 | `BoxView` / `box/BoxView.html` | Box（`<ID> : <場所>`） `#boxViewSelectInput` | 作品名, 巻 | `getBoxDetail` |

- メニューから画面を開き直すと、入力欄・結果テーブル・所持状況はクリアされます。
- 未選択（入力値に一致する候補なし）の場合: 「シリーズを選択してください」等のエラー通知。
- **作品表示の所持状況**（`#titleOwnershipSummary`）: 所持（冊数と巻の範囲）、抜け（1 巻から最大巻までの未所持巻。あれば強調表示）、次の巻（最大巻＋1）を表示。完結済の作品は「次の巻」の代わりに「抜けなく所持しています／抜けている巻があります」。欲しい巻リストに登録がある場合は「欲しい巻 ★ 104, 107〜108巻」を追記（`appendTitleWishLine`）。
- 所持巻の表記（シリーズ表示・作品一覧）: `1〜12巻, 上（抜け: 7巻）`。完結済で抜けがなければ `（完結・抜けなし）`、所持なしは `未所持`。数値以外の巻（`上`・`外伝` 等）は抜けの判定に含めません。
- 入力値の解決は `getAutocompleteValue()`（完全一致を優先し、部分一致は 1 件のときのみ採用。[05 章](05_client_common.md#55-オートコンプリート)参照）。部分一致が複数なら「作品を選択してください」等のエラー。

## 4.5 一覧・管理画面

シリーズ・作品・箱・書籍の一覧で、参照と管理（追加・インライン編集、書籍は削除）を 1 画面で行います（旧マスタ管理画面は統合して廃止）。タブ表示時に**全件を取得**し、絞り込み・並べ替え・ページング（1 ページ 20 件）は画面側で行います（[05 章 5.12 createListFilter](05_client_common.md#512-一覧の絞り込み並べ替え)）。

```
[追加] [統合]          ← .master-toolbar（[統合] はシリーズ一覧のみ）
┌ 追加フォーム ┐        ← 初期非表示。[追加] でトグル（他フォームは閉じる）
└─────────────┘
┌ 絞り込み欄 ┐          ← キーワード＋選択式、件数、[クリア]
└───────────┘
┌ 一覧テーブル ─────────┬──────────┐
│ ...                   │ [編集] ([削除]) │  ← 操作列
└───────────────────────┴──────────┘
« 前へ 1 2 3 … 次へ »
```

| 画面 | View / ファイル | 列 | API | 絞り込み（選択式） | キーワード対象 | 初期の並び |
|---|---|---|---|---|---|---|
| シリーズ一覧 | `SeriesListView` | SeriesID, シリーズ名, 操作 | `getSeriesMaster` | — | ID・シリーズ名 | シリーズ名 昇順 |
| 作品一覧 | `TitleListView` | TitleID, 作品名, シリーズ, 種別, 完結, 所持巻（抜けを含む）, 操作 | `getTitleListWithOwnership` | 種別 / 完結 / 所持（抜けあり・抜けなし・未所持）/ シリーズ | 作品名・シリーズ名・所持巻 | 作品名 昇順 |
| 箱一覧 | `BoxListView` | BoxID, 保管場所, 操作 | `getBoxMaster` | — | ID・保管場所 | BoxID 昇順 |
| 書籍一覧 | `LibraryListView` | ID, 作品名, 巻数, Box, 追加日, 操作 | `getLibraryListAll` | 種別 / Box / 追加月 | ID・作品名・巻数・Box・追加日 | 追加日 新しい順 |

- 表の上の絞り込み欄: キーワード（部分一致・大文字小文字無視）、選択式の絞り込み（選択肢は「すべて」＋データ中の値）、件数「n件 ／ 全m件」、[クリア]（条件があるときだけ表示）。
- **見出しをクリックすると並べ替え**（もう一度押すと逆順。▲▼ で表示）。作品一覧の「所持巻」は抜けの数→所持冊数の順、書籍一覧の「作品名」は作品名→巻数の順、「巻数」は数値の巻を数値順で並べます。
- 絞り込み条件・並び順は、他の画面へ移動して戻っても保持されます（再読込時はデータだけ入れ替え）。追加・編集・削除の後も一覧を再取得し、条件は保持します。
- 作品一覧の「所持」: 1 冊も登録がない＝未所持、1 巻から最大巻までに未所持の巻がある＝抜けあり、それ以外＝抜けなし（数値以外の巻は判定に含めない）。
- メニューから画面を開き直すと、追加フォームは閉じます（入力値は残ります）。

### 編集・削除

- 各行の [編集] でインライン編集（[05 章 5.7](05_client_common.md#57-インライン編集)）。ID 列と集計列（所持巻・追加日）は編集できません。
- 作品の種別（`漫画` / `ラノベ`）・完結（`連載中` / `完結済` / `未完結`）は選択式。
- 書籍のみ各行に [削除]。1 回目で「本当に削除」に変わり、4 秒以内にもう一度押すと削除。他の一覧（作品・シリーズ・Box）には削除なし。
- PC・タブレット（721px 以上）では表ごとに列幅を指定（合計 100%）。操作列は [保存] [取消]（書籍は [編集] [削除]）が並ぶ幅を確保。
- シリーズは同じ名前を、作品は同じ名前・同じ種別を登録・更新できません（エラー通知）。作品名が同じでも種別（漫画／ラノベ）が違えば登録できます。
- 同じ名前の作品は、作品を選ぶすべての入力欄・書籍の一覧で「作品名（種別）」と表示されます。作品名だけを入力した場合は候補が複数となり、選択を求めます。
- 追加・更新成功時は一覧の再読込と、各画面の選択肢（`refreshMasterData`）を更新（書籍は最近追加・サマリーを再読込）。

### 追加フォーム

| 画面 | 項目 | 備考 |
|---|---|---|
| シリーズ一覧 | シリーズ名 `#newSeriesName` | 必須。ID は自動採番。API `addSeriesMasterWeb` |
| 作品一覧 | 作品名 `#newTitleName`、シリーズ `#newTitleSeriesInput`（オートコンプリート）、種別 `#newTitleType`、完結状態 `#newTitleCompleted` | 作品名・シリーズは必須。API `addTitleMasterWeb` |
| 箱一覧 | BoxID `#newBoxId`、場所 `#newBoxPlace` | 必須。BoxID は**利用者が入力**、重複不可。API `addBoxMasterWeb` |
| 書籍一覧 | 作品名 `#libraryAddTitleInput`（datalist）、巻数 `#libraryAddVolumeInput`、Box `#libraryAddBoxInput`（datalist、`<ID> : <場所>`） | すべて必須。巻数は巻数式（例 `1-31` / `1, 3, 5-7`）で一括登録可。候補は画面を開いたときに取得（`loadLibraryAddForm`）。API `addNewVolumeWeb` |

### シリーズの統合（シリーズ一覧）

| 項目 | 内容 |
|---|---|
| 入力 | まとめるシリーズ `#seriesMergeFromInput` → 残すシリーズ `#seriesMergeToInput` |
| 操作 | ツールバーの [統合]。同じシリーズが別名で登録されているときに使う。[統合する] は 2 回押しで確定（4 秒で戻る）。まとめるシリーズの作品・アニメ作品を残すシリーズに付け替え、まとめるシリーズは削除 |
| API | `mergeSeries` |

書籍追加の処理フロー:

```
[保存] → addLibraryMaster()
   ├ 作品・Box を datalist から ID に解決、巻数を取得
   ├ いずれか空 → エラー通知「作品名・巻数・Boxは必須です」
   └ addNewVolumeWeb(titleId, volume, boxId)
        ├ 成功 → 成功通知、フォームクリア、最近追加／サマリー／一覧／選択肢を再読込
        └ 失敗 → エラー通知（重複巻・巻数式エラー等）
```

## 4.7 写真で確認・登録画面

`PhotoImportView`（`client/library/PhotoImportView.html`）。**初期表示画面**で、メニューの「登録」グループから開きます。ロジックは `client/library/PhotoImport.html`、表示時の処理は `loadPhotoImportView()`。
画面は常時表示のパネル（`#photoImportPanel`、クラス `photo-import-panel`）1 つで構成します。一覧・管理画面の `.master-form` と違い、画面切替時（`resetViewState`）に閉じられません。
本の表紙・背表紙を撮って**持っている巻かを確認（確認モード）**し、持っていない本は**そのまま登録（登録モード）**できます。書店での所持確認と、購入後の登録を 1 画面で行います。
画面を開くたびに前回の写真・解析結果・登録結果をクリアします（解析・登録の処理中は残します）。

```
① 写真選択（最大5枚）→ サムネイル表示（タップで拡大ビューア）
② [チェック] → analyzeBookSpines（数十秒かかることがある。インラインローディング表示）
③ 確認モード: 1 冊 = 1 カードで所持チェックの判定を表示。上部に「n冊中 所持済み x冊 ／ 未所持 y冊」
     作品・巻数の読み取り違いはカード内の入力欄で修正（即時に再判定）
     マスタにない作品は [作品を追加] から作品（＋必要ならシリーズ）を追加できる
     ここで終われば登録しない（書店での確認用）
④ [未所持の本を登録する（n冊）] → 登録モード
     所持済みの本は非表示・登録対象外、未所持の本のみチェック ON
     作品・巻数・Box を確認・修正。マスタにない作品は [作品を追加]、必要に応じて [最終巻]
     [確認結果に戻る] で確認モードへ
⑤ [登録確定（n件）] → bulkAddLibraryFromPhoto → 結果表示
```

モードは `photoImportState.mode`（`check` / `register`）で、パネルのクラス `is-check-mode` により表示を切り替えます。登録用の要素（チェック・Box・状態・最終巻・一括Box・登録確定）はクラス `register-only`（[作品を追加] は両モードで表示）、[未所持の本を登録する] は `check-only`。

### 画面項目

| 区分 | 項目 | 要素 | 備考 |
|---|---|---|---|
| 写真 | 本の写真 | `#photoImportFiles` | `image/*`、複数選択、最大 5 枚・各 20MB まで |
| | プレビュー | `#photoImportPreview` | サムネイル。押すと拡大ビューア（`#photoImportViewer`、画像タップで拡大／縮小） |
| | チェックボタン | `#photoImportAnalyzeButton` | 処理中は無効化 |
| 確認 | まとめ | `#photoImportSummary` | 「n冊中 所持済み x冊 ／ 未所持 y冊」 |
| | 登録へ進む | `#photoImportStartRegister` | 確認モードのみ。「未所持の本を登録する（n冊）」。未所持 0 冊・処理中は無効 |
| 登録 | 一括Box | `#photoImportBulkBox` | 変更すると**全行**の Box を上書き。解析時、未選択ならサーバーの初期値を設定 |
| | 行カード | `#photoImportRows` | 下表 |
| | 登録確定 | `#photoImportRegisterButton` | 登録モードのみ。「照合済み」かつチェック済みの行数を表示。0 件・処理中は無効 |
| | 確認結果に戻る | `#photoImportBackToCheck` | 登録モードのみ |
| 結果 | 結果表示 | `#photoImportResult` | 成功／重複スキップ／失敗の件数と明細、完結済に更新した作品 |

行カードの項目（「登録のみ」は登録モードでのみ表示）:

| 項目 | 内容 |
|---|---|
| 判定 | 所持チェックの判定バッジ＋説明（下記）。カード左端の色も判定に合わせる |
| チェック（登録のみ） | 登録対象にするか（初期値: 未所持なら ON、所持済みなら OFF） |
| 作品 | 作品名入力（datalist）。**完全一致**した作品のみ選択扱い |
| 巻数 | 1 巻のみ（巻数式の範囲・複数指定は入力エラー） |
| Box（登録のみ） | セレクト |

| 読み取り情報 | 写真番号リンク（拡大表示）、AI が読み取った作品名・巻数（修正しても変わらない）、候補（2 件以上の場合）、AI の補足 |
| 欲しい巻に追加（確認のみ） | 作品・巻数が決まり、所持済みでも欲しい巻でもない行に表示。押すと `addWishes` で追加 |

### 行の状態判定（`getPhotoImportStatus`）

上から順に判定します。

| 順 | 条件 | 状態 | 説明 |
|---|---|---|---|
| 1 | 作品未選択 | マスタ未登録 | 作品マスタに無い作品です（自動作成しません） |
| 2 | 巻数が空 | 要確認 | 巻数を入力してください |
| 3 | 巻数が不正、または 2 巻以上 | 入力エラー | 巻数は1つだけ入力してください |
| 4 | 要確認フラグあり | 要確認 | 作品・巻数を確認して「OK」を押してください |
| 5 | Box 未選択 | 入力エラー | Boxを選択してください |
| 6 | 登録済み（`existingKeys`）、またはチェック済みの前の行と同じ作品・巻 | 重複 | 同じ作品・巻数が登録済みです |
| 7 | 上記以外 | 照合済み | 登録可能 |

要確認フラグは、照合結果が `exact` 以外、または AI が `uncertain` を返した行で ON になります。作品・巻数を編集するか [OK] で OFF になります。

### 所持チェックの判定（`getPhotoImportVerdict`）

登録済みの巻（`existingKeys`）と、この一覧の同じ作品の未所持の巻（確認モードでは全行＝一緒に買うものとして扱う、登録モードではチェック済みの行）を合わせて判定します。**登録可否には影響しません**。

| 判定 | 条件 | 表示例 | 色 |
|---|---|---|---|
| 所持済み | 登録済みの巻 | 所持: 1〜103巻 | 緑 |
| 未所持・続きの巻 | 1 巻からその巻の前まで抜けがない | この一覧の104巻と合わせて続きになります ／ 所持: 1〜103巻 | 青 |
| 未所持・抜けていた巻 | 所持済みの最大巻より前 | 抜けている巻を埋められます ／ 所持: … | 青 |
| 未所持・間が飛ぶ | 1 巻からその巻の前までに未所持の巻がある | 6〜7巻が未所持です ／ 所持: … | 黄 |
| 未所持の作品 | 作品マスタに無い、または 1 冊も所持していない | 作品マスタに無い作品です | 灰 |
| 巻数不明 | 巻数を読み取れない | 所持: … | 灰 |

- 作品が特定でき、要確認フラグが ON の場合は「要確認（読み取りがあいまいです）」を付けます。
- 欲しい巻リストにある巻は、説明の先頭に「★欲しい巻リストにあります」を付けます。
- 作品・巻数・チェックを変えると全カードを即時に再判定します。確認モードで巻数を直して所持済みでなくなった本は、登録モードに表示されます。

### 作品追加後の動き

追加した作品を当該行に設定し、**同じ読み取り作品名で作品未選択の他の行**にも同じ作品を設定します（他の行は AI が `uncertain` の場合のみ要確認）。各画面の選択肢も再構築します（`refreshMasterData`）。

### 登録確定後の動き

- 登録できた行は一覧から消し、重複と判定された行は登録済みとして扱います。
- 対応が必要な行（チェック済みで重複以外）が残っていなければ、写真と一覧をクリアします。
- 1 件以上登録できた場合は、最近追加・サマリーを再読込します（書籍一覧は画面を開いたときに再取得）。

## 4.8.1 アニメ画面

メニューを「アニメ」モードに切り替えると表示。ファイルは `client/anime/`、ロジックは `Anime.html`。書籍の画面とは独立しており、共通なのはシリーズ（`M_Series`）のみ。書籍の所蔵サマリー・最近追加した漫画・作品名検索は表示しません。

データは画面を開くたびに `getAnimeData()` で全件取得し（`loadAnimeData`）、絞り込みはクライアント側で行います。

### 視聴中の一覧（`AnimeWatchingView`）

| 区分 | 内容 |
|---|---|
| 視聴中 | 状況が `視聴中` の期をカード表示（最近更新した順）。期名・作品名（期名と違う場合）・種別・「N話まで視聴」。[+1話]（話数 +1）、[視聴済にする]、[中断]（`視聴中断`）で `updateAnimeWatch` を呼び、一覧を再読込 |
| 視聴予定 | 状況が `視聴予定` の期（登録順）。[視聴開始] で `視聴中` に変更 |

### シリーズ別検索（`AnimeSeriesView`）

アニメが登録されているシリーズだけを候補に出します（`#animeSeriesSelectInput`）。[表示] で、まとめ（期の件数と種別内訳・状況内訳・視聴話数の合計）と、期の表（作品 / 期 / 種別 / 視聴済話数 / 状況。作品の登録順→期の登録順）を表示。続けて同じシリーズの書籍を「書籍（所持巻）」欄に表示（`getSeriesDetail` で作品ごとの所持巻を取得し、書籍のシリーズ別検索と同じ `formatOwnershipText` で「1〜5巻（抜け: 3巻）」の形にする）。画面を開き直すと入力・結果をクリア（`SEARCH_VIEW_IDS`）。

### アニメ一覧（`AnimeListView`）

上部の [期ごと] / [作品ごと] で表示単位を切り替えます（選択は画面を移っても保持）。どちらも書籍の一覧と同じ `createListFilter` で、見出しクリックで並べ替え、各行の [編集] でインライン編集します。追加は「アニメ登録」から行うため [追加] はありません（旧アニメ作品マスタ管理・アニメ期マスタ管理は統合して廃止）。

| 表示 | 列 | 絞り込み | 編集（保存先） |
|---|---|---|---|
| 期ごと（`animeListTable`、30 件ずつ） | 作品 / 期 / 種別 / 話数 / 状況 / 更新日 / 操作 | キーワード（作品・期・シリーズ名）、状況・種別・シリーズ。初期は作品名順 | 作品・期名・種別（選択）・話数・状況（選択）を `updateAnimeSeasonMaster`。作品を変えるとその期を別の作品に付け替え。各行に [削除]（2 回押しで確定、`deleteAnimeSeason`） |
| 作品ごと（`animeWorkListTable`、30 件ずつ） | 作品名 / シリーズ / 期（期の数） / 視聴話数（合計） / 操作 | キーワード（作品名・シリーズ名）、シリーズ。初期は作品名順 | 作品名・シリーズを `updateAnimeMaster`（シリーズは既存の名前のみ、空欄可） |

視聴中断の期を探すときは、期ごとで状況を絞り込みます。

### アニメ登録（`AnimeEntryView`）

| 項目 | 要素 | 備考 |
|---|---|---|
| 作品名 | `#animeEntryAnimeInput` | 登録済み作品を候補表示。一致すれば「登録済みの作品に期を追加」、しなければ「新しい作品として登録」と表示（`syncAnimeEntrySeries`） |
| シリーズ | `#animeEntrySeriesInput` | 新しい作品のときだけ表示。全シリーズ（書籍と共通）を候補表示。空欄なら作品名と同じシリーズ。未登録のシリーズ名は新規作成 |
| 期名 | `#animeEntrySeasonInput` | 空欄なら作品名 |
| 種別 | `#animeEntryType` | TV / OVA / 劇場版 / その他 |
| 視聴済話数 | `#animeEntryEpisodesInput` | 空欄可 |
| 状況 | `#animeEntryStatus` | 初期値 `視聴中` |

[登録する] で `addAnimeSeasonWeb`。成功後は期名・話数・シリーズ欄をクリアし、書籍側の選択肢も再読込（`refreshMasterData`。シリーズが増えた場合のため）。下部に最近更新した期（10 件）を表示。

---|---|---|
| 作品 | AnimeID / 作品名 / シリーズ | `updateAnimeMaster`（シリーズは既存の名前のみ） |
| 期 | SeasonID / 作品 / 期名 / 種別 / 視聴済話数 / 状況 | `updateAnimeSeasonMaster`。キーワードはシリーズ名にも一致。各行に [削除]（2 回押しで確定、`deleteAnimeSeason`） |
