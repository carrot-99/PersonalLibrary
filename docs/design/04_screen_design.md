# 04. 画面設計

## 4.1 画面レイアウト

`client/Index.html` が唯一の HTML ページで、以下の領域で構成されます。

```
┌──────────┬──────────────────────────────────────────────────────────┐
│          │ にんじん図書館                 [通知エリア globalNotification]│
│ サイド    ├──────────────────────────────────────────┬───────────────┤
│ メニュー  │ サマリーパネル（6 項目）                  │ 最近追加した   │
│ (Navbar) ├──────────────────────────────────────────┤ 漫画           │
│          │                                          │ (作品名/巻数)  │
│ 登録      │ コンテンツ領域（tabContent）              │  最大 10 件    │
│ 検索      │   選択中の View を 1 つだけ表示            │               │
│ 一覧      │                                          │               │
│ マスタ管理│                                          │               │
└──────────┴──────────────────────────────────────────┴───────────────┘
```

| 領域 | 要素 ID / クラス | 内容 |
|---|---|---|
| メニュー開閉ボタン | `#menuToggle` | タブレット幅以下で表示。サイドメニューを開閉 |
| サイドメニュー | `#sideMenu` | `Navbar.html` を埋め込み |
| 検索欄 | `#globalSearchInput` | 作品名（datalist）で検索し、作品別検索（`TitleView`）を開いてその作品の所持状況を表示（`runGlobalSearch`）。完全一致、なければ部分一致が 1 件のときに確定。複数・0 件はエラー通知 |
| 通知エリア | `#globalNotification` | 成功（4 秒）・エラー（6 秒）で自動消去 |
| サマリーパネル | `.top-summary-panel` | 所蔵冊数 / 漫画所蔵冊数 / ラノベ所蔵冊数 / 登録作品数 / 登録Box数 / 最新登録（`getLibrarySummary`） |
| コンテンツ領域 | `#tabContent` | 各 View |
| 最近追加 | `#globalRecentLibraryTable` | 作品名・巻数（`getRecentLibrary`） |

サマリーパネルと最近追加は、**初期表示時とタブ切替のたびに再取得**されます。

### レスポンシブ

| 画面幅 | レイアウト |
|---|---|
| 1101px 以上（PC） | サイドメニュー常時表示、コンテンツと「最近追加」を横並び |
| 721〜1100px（タブレット） | ☰ ボタンでサイドメニュー開閉（外側の暗幕タップでも閉じる）、縦積み、サマリー 3 列 |
| 720px 以下（スマホ） | タッチ操作向けの専用レイアウト（下表） |

スマホ（720px 以下）の主な違い。スタイルは `Styles.html` 末尾の `@media (max-width: 720px)` にまとめ、他のルールより優先させています。

| 対象 | スマホでの表示 |
|---|---|
| 上部バー | タイトル・検索欄・通知エリアを画面上部に固定（スクロールしても表示）。検索欄は全幅。☰ は 48px |
| サイドメニュー | 幅は画面の 86%（最大 340px）、ボタン高さ 52px |
| サマリー | 3 列・2 段に圧縮 |
| 入力欄・ボタン | 文字 16px（iPhone の入力時ズームを防ぐ）、高さ 48px 以上。画面内の単独ボタン（[表示] [保存] [解析] 等）は全幅 |
| ツールバー | ボタンを横並び・等幅（高さ 52px） |
| テーブル | 文字を省略せず折り返し、列幅は内容に合わせる。シリーズ・作品・書籍のマスタ管理／一覧では自動採番の ID 列を非表示（箱は BoxID を利用者が入力するため表示）。[編集]・ページングのボタンは 44〜48px |
| インライン編集 | 入力欄の最小幅を確保し、はみ出す分は画面内で横スクロール。入力欄には列名をプレースホルダー表示 |
| 写真から登録 | チェック・ボタン類を拡大、作品追加フォームは 1 列。[登録確定] は画面下部に固定（`position: sticky`） |

## 4.4 検索画面

3 画面とも同じ構成です：オートコンプリート入力 ＋ 「表示」ボタン ＋ 結果テーブル（結果 0 件時は非表示）。検索中はインラインローディングを表示します。

| 画面 | View / ファイル | 入力 | 結果列 | API |
|---|---|---|---|---|
| シリーズ表示 | `SeriesView` / `series/SeriesView.html` | シリーズ名 `#seriesSelectInput` | 作品名, 所持巻数, 所持巻（抜けを含む） | `getSeriesDetail` |
| 作品表示 | `TitleView` / `title/TitleView.html` | 作品名 `#titleViewSelectInput` | 所持状況（下記）＋ 巻, BoxID（巻数順） | `getTitleDetail` |
| Box 表示 | `BoxView` / `box/BoxView.html` | Box（`<ID> : <場所>`） `#boxViewSelectInput` | 作品名, 巻 | `getBoxDetail` |

- メニューから画面を開き直すと、入力欄・結果テーブル・所持状況はクリアされます。
- 未選択（入力値に一致する候補なし）の場合: 「シリーズを選択してください」等のエラー通知。
- **作品表示の所持状況**（`#titleOwnershipSummary`）: 所持（冊数と巻の範囲）、抜け（1 巻から最大巻までの未所持巻。あれば強調表示）、次の巻（最大巻＋1）を表示。完結済の作品は「次の巻」の代わりに「抜けなく所持しています／抜けている巻があります」。欲しい巻リストに登録がある場合は「欲しい巻 ★ 104, 107〜108巻」を追記（`appendTitleWishLine`）。
- 所持巻の表記（シリーズ表示・作品一覧）: `1〜12巻, 上（抜け: 7巻）`。完結済で抜けがなければ `（完結・抜けなし）`、所持なしは `未所持`。数値以外の巻（`上`・`外伝` 等）は抜けの判定に含めません。
- 入力値の解決は `getAutocompleteValue()`（完全一致を優先し、部分一致は 1 件のときのみ採用。[05 章](05_client_common.md#55-オートコンプリート)参照）。部分一致が複数なら「作品を選択してください」等のエラー。

## 4.6 マスタ管理画面

### 共通構成

```
[追加] [検索]          ← .master-toolbar
┌ 追加フォーム ┐        ← 初期非表示。[追加] でトグル（他フォームは閉じる）
└─────────────┘
┌ 検索フォーム ┐        ← 初期非表示。[検索] でトグル
│ キーワード [検索実行] │
└─────────────┘
┌ 一覧テーブル ┐        ← 初期非表示。[検索実行] で表示
│ ... | [編集] │
└─────────────┘
```

- タブ表示時にマスタを取得してクライアントキャッシュ `masterCache.<種別>` に保持。
- 一覧は**検索実行時に表示**されます。キーワードが空のまま検索実行すると全件表示（書籍マスタ管理のみ最大 300 件。下記）。
  ツールバーのボタン（[追加] [検索]）を押すと一覧は非表示に戻ります。
  キーワードは全項目に対する部分一致（大文字小文字無視）。0 件ならテーブル非表示。
- メニューから画面を開き直すと、フォーム・一覧は閉じ、検索キーワードはクリアされます（追加フォームの入力値は残ります）。
- 更新の後は、検索キーワードが入力済みなら絞り込み結果を自動で再表示。
- PC・タブレット（721px 以上）では表ごとに列幅を指定（合計 100%）。操作列は [保存] [取消]（書籍は [編集] [削除]）が並ぶ幅を確保。
- シリーズは同じ名前を、作品は同じ名前・同じ種別を登録・更新できません（エラー通知）。作品名が同じでも種別（漫画／ラノベ）が違えば登録できます。
- 同じ名前の作品は、作品を選ぶすべての入力欄・書籍の一覧で「作品名（種別）」と表示されます。作品名だけを入力した場合は候補が複数となり、選択を求めます。
- 各行の [編集] でインライン編集（[05 章 5.7](05_client_common.md#57-インライン編集)）。
- 追加・更新成功時はマスタ再読込と、各画面の選択肢（`refreshMasterData`）を更新。


## 4.7 写真で確認・登録画面

`PhotoImportView`（`client/library/PhotoImportView.html`）。**初期表示画面**で、メニューの「登録」グループから開きます。ロジックは `client/library/PhotoImport.html`、表示時の処理は `loadPhotoImportView()`。
画面は常時表示のパネル（`#photoImportPanel`、クラス `photo-import-panel`）1 つで構成します。マスタ管理画面の `.master-form` と違い、画面切替時（`resetViewState`）に閉じられません。
本の表紙・背表紙を撮って**持っている巻かを確認（確認モード）**し、持っていない本は**そのまま登録（登録モード）**できます。書店での所持確認と、購入後の登録を 1 画面で行います。
画面を開くたびに前回の写真・解析結果・登録結果をクリアします（解析・登録の処理中は残します）。

```
① 写真選択（最大5枚）→ サムネイル表示（タップで拡大ビューア）
② [チェック] → analyzeBookSpines（数十秒かかることがある。インラインローディング表示）
③ 確認モード: 1 冊 = 1 カードで所持チェックの判定を表示。上部に「n冊中 所持済み x冊 ／ 未所持 y冊」
     作品・巻数の読み取り違いはカード内の入力欄で修正（即時に再判定）
     マスタにない作品は [作品を追加] から作品（＋必要ならシリーズ）を追加できる
     ここで終われば登録しない（書店での確認用）
④ [未所持の本を登録する（n冊）] → 登録モード
     所持済みの本は非表示・登録対象外、未所持の本のみチェック ON
     作品・巻数・Box を確認・修正。マスタにない作品は [作品を追加]、必要に応じて [最終巻]
     [確認結果に戻る] で確認モードへ
⑤ [登録確定（n件）] → bulkAddLibraryFromPhoto → 結果表示
```

モードは `photoImportState.mode`（`check` / `register`）で、パネルのクラス `is-check-mode` により表示を切り替えます。登録用の要素（チェック・Box・状態・最終巻・一括Box・登録確定）はクラス `register-only`（[作品を追加] は両モードで表示）、[未所持の本を登録する] は `check-only`。

### 画面項目

| 区分 | 項目 | 要素 | 備考 |
|---|---|---|---|
| 写真 | 本の写真 | `#photoImportFiles` | `image/*`、複数選択、最大 5 枚・各 20MB まで |
| | プレビュー | `#photoImportPreview` | サムネイル。押すと拡大ビューア（`#photoImportViewer`、画像タップで拡大／縮小） |
| | チェックボタン | `#photoImportAnalyzeButton` | 処理中は無効化 |
| 確認 | まとめ | `#photoImportSummary` | 「n冊中 所持済み x冊 ／ 未所持 y冊」 |
| | 登録へ進む | `#photoImportStartRegister` | 確認モードのみ。「未所持の本を登録する（n冊）」。未所持 0 冊・処理中は無効 |
| 登録 | 一括Box | `#photoImportBulkBox` | 変更すると**全行**の Box を上書き。解析時、未選択ならサーバーの初期値を設定 |
| | 行カード | `#photoImportRows` | 下表 |
| | 登録確定 | `#photoImportRegisterButton` | 登録モードのみ。「照合済み」かつチェック済みの行数を表示。0 件・処理中は無効 |
| | 確認結果に戻る | `#photoImportBackToCheck` | 登録モードのみ |
| 結果 | 結果表示 | `#photoImportResult` | 成功／重複スキップ／失敗の件数と明細、完結済に更新した作品 |

行カードの項目（「登録のみ」は登録モードでのみ表示）:

| 項目 | 内容 |
|---|---|
| 判定 | 所持チェックの判定バッジ＋説明（下記）。カード左端の色も判定に合わせる |
| チェック（登録のみ） | 登録対象にするか（初期値: 未所持なら ON、所持済みなら OFF） |
| 作品 | 作品名入力（datalist）。**完全一致**した作品のみ選択扱い |
| 巻数 | 1 巻のみ（巻数式の範囲・複数指定は入力エラー） |
| Box（登録のみ） | セレクト |
| 状態（登録のみ） | 状態バッジ＋説明。「要確認」で巻数ありの場合は [OK] ボタン |
| 読み取り情報 | 写真番号リンク（拡大表示）、AI が読み取った作品名・巻数（修正しても変わらない）、候補（2 件以上の場合）、AI の補足 |
| 欲しい巻に追加（確認のみ） | 作品・巻数が決まり、所持済みでも欲しい巻でもない行に表示。押すと `addWishes` で追加 |
| 作品を追加 | 作品名（読み取り結果を初期値）、既存シリーズ／新規シリーズ（作品名を初期値）、種別、完結状態 → [追加して選択] |
| 最終巻（登録のみ） | ON で登録時に作品を `完結済` に更新。作品未選択時は非表示、既に完結済の作品は「完結済の作品」と表示し操作不可 |

### 行の状態判定（`getPhotoImportStatus`）

上から順に判定します。

| 順 | 条件 | 状態 | 説明 |
|---|---|---|---|
| 1 | 作品未選択 | マスタ未登録 | 作品マスタに無い作品です（自動作成しません） |
| 2 | 巻数が空 | 要確認 | 巻数を入力してください |
| 3 | 巻数が不正、または 2 巻以上 | 入力エラー | 巻数は1つだけ入力してください |
| 4 | 要確認フラグあり | 要確認 | 作品・巻数を確認して「OK」を押してください |
| 5 | Box 未選択 | 入力エラー | Boxを選択してください |
| 6 | 登録済み（`existingKeys`）、またはチェック済みの前の行と同じ作品・巻 | 重複 | 同じ作品・巻数が登録済みです |
| 7 | 上記以外 | 照合済み | 登録可能 |

要確認フラグは、照合結果が `exact` 以外、または AI が `uncertain` を返した行で ON になります。作品・巻数を編集するか [OK] で OFF になります。

### 所持チェックの判定（`getPhotoImportVerdict`）

登録済みの巻（`existingKeys`）と、この一覧の同じ作品の未所持の巻（確認モードでは全行＝一緒に買うものとして扱う、登録モードではチェック済みの行）を合わせて判定します。**登録可否には影響しません**。

| 判定 | 条件 | 表示例 | 色 |
|---|---|---|---|
| 所持済み | 登録済みの巻 | 所持: 1〜103巻 | 緑 |
| 未所持・続きの巻 | 1 巻からその巻の前まで抜けがない | この一覧の104巻と合わせて続きになります ／ 所持: 1〜103巻 | 青 |
| 未所持・抜けていた巻 | 所持済みの最大巻より前 | 抜けている巻を埋められます ／ 所持: … | 青 |
| 未所持・間が飛ぶ | 1 巻からその巻の前までに未所持の巻がある | 6〜7巻が未所持です ／ 所持: … | 黄 |
| 未所持の作品 | 作品マスタに無い、または 1 冊も所持していない | 作品マスタに無い作品です | 灰 |
| 巻数不明 | 巻数を読み取れない | 所持: … | 灰 |

- 作品が特定でき、要確認フラグが ON の場合は「要確認（読み取りがあいまいです）」を付けます。
- 欲しい巻リストにある巻は、説明の先頭に「★欲しい巻リストにあります」を付けます。
- 作品・巻数・チェックを変えると全カードを即時に再判定します。確認モードで巻数を直して所持済みでなくなった本は、登録モードに表示されます。

### 作品追加後の動き

追加した作品を当該行に設定し、**同じ読み取り作品名で作品未選択の他の行**にも同じ作品を設定します（他の行は AI が `uncertain` の場合のみ要確認）。各画面の選択肢も再構築します（`refreshMasterData`）。

### 登録確定後の動き

- 登録できた行は一覧から消し、重複と判定された行は登録済みとして扱います。
- 対応が必要な行（チェック済みで重複以外）が残っていなければ、写真と一覧をクリアします。
- 1 件以上登録できた場合は、最近追加・サマリーを再読込します（書籍マスタ管理の一覧は画面を開いたときに再取得）。

## 4.8 欲しい巻リスト画面

`WishListView`（`client/library/WishListView.html`）。メニューの「登録」グループから開きます。ロジックは `client/library/Wish.html`、表示時の処理は `loadWishListView()`（作品候補の設定と一覧の取得）。

| 区分 | 項目 | 要素 | 備考 |
|---|---|---|---|
| 追加 | 作品 | `#wishTitleInput` | datalist。完全一致した作品のみ選択扱い。選ぶと所持巻を取得し [次の巻（N巻）] を表示 |
| | 巻数 | `#wishVolumeInput` | 巻数式（`13` / `13-15` / `1, 3`）。[次の巻] で最大所持巻＋1 を入力 |
| | メモ | `#wishMemoInput` | 任意 |
| | 追加 | `#wishAddButton` | `addWishes`。所持済み・追加済みの巻はスキップし、結果を通知 |
| 一覧 | まとめ | `#wishListSummary` | 「n作品・m冊」 |
| | 作品ごとのカード | `#wishListGroups` | 作品名順。見出しに巻の範囲、各巻に追加日と [削除]（2 回押しで確定、`deleteWish`） |

書籍を登録すると、その巻は自動でリストから外れます（2.3.5 参照）。
