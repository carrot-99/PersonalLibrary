# 04. 画面設計

## 4.1 画面レイアウト

`client/Index.html` が唯一の HTML ページで、以下の領域で構成されます。

```
┌──────────┬──────────────────────────────────────────────────────────┐
│          │ にんじん図書館                 [通知エリア globalNotification]│
│ サイド    ├──────────────────────────────────────────┬───────────────┤
│ メニュー  │ サマリーパネル（6 項目）                  │ 最近追加した   │
│ (Navbar) ├──────────────────────────────────────────┤ 漫画           │
│          │                                          │ (作品名/巻数)  │
│ 検索      │ コンテンツ領域（tabContent）              │  最大 10 件    │
│ 一覧      │   選択中の View を 1 つだけ表示            │               │
│ マスタ管理│                                          │               │
└──────────┴──────────────────────────────────────────┴───────────────┘
```

| 領域 | 要素 ID / クラス | 内容 |
|---|---|---|
| メニュー開閉ボタン | `#menuToggle` | タブレット幅以下で表示。サイドメニューを開閉 |
| サイドメニュー | `#sideMenu` | `Navbar.html` を埋め込み |
| 通知エリア | `#globalNotification` | 成功（4 秒）・エラー（6 秒）で自動消去 |
| サマリーパネル | `.top-summary-panel` | 所蔵冊数 / 漫画所蔵冊数 / ラノベ所蔵冊数 / 登録作品数 / 登録Box数 / 最新登録（`getLibrarySummary`） |
| コンテンツ領域 | `#tabContent` | 各 View |
| 最近追加 | `#globalRecentLibraryTable` | 作品名・巻数（`getRecentLibrary`） |

サマリーパネルと最近追加は、**初期表示時とタブ切替のたびに再取得**されます。

### レスポンシブ

| 画面幅 | レイアウト |
|---|---|
| 1101px 以上（PC） | サイドメニュー常時表示、コンテンツと「最近追加」を横並び |
| 721〜1100px（タブレット） | ☰ ボタンでサイドメニュー開閉、縦積み、サマリー 3 列 |
| 720px 以下（スマホ） | 縦積み、サマリー 2 列、ツールバーのボタンは全幅 |

## 4.4 検索画面

3 画面とも同じ構成です：オートコンプリート入力 ＋ 「表示」ボタン ＋ 結果テーブル（結果 0 件時は非表示）。検索中はインラインローディングを表示します。

| 画面 | View / ファイル | 入力 | 結果列 | API |
|---|---|---|---|---|
| シリーズ表示 | `SeriesView` / `series/SeriesView.html` | シリーズ名 `#seriesSelectInput` | 作品名, 所持巻数 | `getSeriesDetail` |
| 作品表示 | `TitleView` / `title/TitleView.html` | 作品名 `#titleViewSelectInput` | 巻, BoxID | `getTitleDetail` |
| Box 表示 | `BoxView` / `box/BoxView.html` | Box（`<ID> : <場所>`） `#boxViewSelectInput` | 作品名, 巻 | `getBoxDetail` |

- メニューから画面を開き直すと、入力欄と結果テーブルはクリアされます。
- 未選択（入力値に一致する候補なし）の場合: 「シリーズを選択してください」等のエラー通知。
- 入力値の解決は `getAutocompleteValue()`（部分一致で最初の候補を採用。[05 章](05_client_common.md#55-オートコンプリート)参照）。

## 4.5 一覧画面

すべて参照専用・1 ページ 20 件のページング（[05 章 renderPagedTableDOM](05_client_common.md#54-テーブル描画)）。タブ表示時に 1 ページ目を読み込みます。

| 画面 | View / ファイル | 列 | API | ページング方式 |
|---|---|---|---|---|
| シリーズ一覧 | `SeriesListView` | SeriesID, シリーズ名 | `getSeriesMaster` | 全件取得しクライアントで切り出し |
| 作品一覧 | `TitleListView` | TitleID, 作品名, シリーズ, 種別, 完結 | `getTitleMaster` | 同上 |
| 箱一覧 | `BoxListView` | BoxID, 保管場所 | `getBoxMaster` | 同上 |
| 書籍一覧 | `LibraryListView` | ID, 作品名, 巻数, Box, 追加日 | `getLibraryPage(page, 20)` | サーバー側ページング |

作品一覧のみ、上部に種別フィルタボタン（`全作品` / `漫画` / `ラノベ`）があり、選択中のフィルタはページ移動後も維持されます（`currentTitleListFilter`）。

## 4.6 マスタ管理画面

### 共通構成

```
[追加] [検索]          ← .master-toolbar（書籍マスタ管理のみ [写真から登録] あり）
┌ 追加フォーム ┐        ← 初期非表示。[追加] でトグル（他フォームは閉じる）
└─────────────┘
┌ 検索フォーム ┐        ← 初期非表示。[検索] でトグル
│ キーワード [検索実行] │
└─────────────┘
┌ 一覧テーブル ┐        ← 初期非表示。[検索実行] で表示
│ ... | [編集] │
└─────────────┘
```

- タブ表示時にマスタを取得してクライアントキャッシュ `masterCache.<種別>` に保持。
- 一覧は**検索実行時に表示**されます。キーワードが空のまま検索実行すると全件表示。
  ツールバーのボタン（[追加] [検索] [写真から登録]）を押すと一覧は非表示に戻ります。
  キーワードは全項目に対する部分一致（大文字小文字無視）。0 件ならテーブル非表示。
- メニューから画面を開き直すと、フォーム・一覧は閉じ、検索キーワードはクリアされます（追加フォームの入力値は残ります）。
- 更新・写真から登録の後は、検索キーワードが入力済みなら絞り込み結果を自動で再表示。
- 各行の [編集] でインライン編集（[05 章 5.7](05_client_common.md#57-インライン編集)）。
- 追加・更新成功時はマスタ再読込と、各画面の選択肢（`refreshMasterData`）を更新。

書籍追加の処理フロー:

```
[保存] → addLibraryMaster()
   ├ 作品・Box を datalist から ID に解決、巻数を取得
   ├ いずれか空 → エラー通知「作品名・巻数・Boxは必須です」
   └ addNewVolumeWeb(titleId, volume, boxId)
        ├ 成功 → 成功通知、フォームクリア、最近追加／サマリー／一覧／選択肢を再読込
        └ 失敗 → エラー通知（重複巻・巻数式エラー等）
```

### 4.6.5 写真から登録（書籍マスタ管理内）

書籍マスタ管理のツールバー [写真から登録] で開くフォーム（`#libraryPhotoForm`）。ロジックは `client/library/PhotoImport.html`。
フォームを開くたびに前回の写真・解析結果・登録結果をクリアします（解析・登録の処理中は残します）。

```
① 写真選択（最大5枚）→ サムネイル表示（タップで拡大ビューア）
② [解析] → analyzeBookSpines（数十秒かかることがある。インラインローディング表示）
③ 確認画面: 1 冊 = 1 行のカードで、作品・巻数・Box を確認・修正
     マスタにない作品は行内の [作品を追加] から作品（＋必要ならシリーズ）を追加
     必要に応じて [最終巻] を指定
④ [登録確定（n件）] → bulkAddLibraryFromPhoto → 結果表示
```

#### 画面項目

| 区分 | 項目 | 要素 | 備考 |
|---|---|---|---|
| 写真 | 背表紙の写真 | `#photoImportFiles` | `image/*`、複数選択、最大 5 枚・各 20MB まで |
| | プレビュー | `#photoImportPreview` | サムネイル。押すと拡大ビューア（`#photoImportViewer`、画像タップで拡大／縮小） |
| | 解析ボタン | `#photoImportAnalyzeButton` | 処理中は無効化 |
| 確認 | 一括Box | `#photoImportBulkBox` | 変更すると**全行**の Box を上書き。解析時、未選択ならサーバーの初期値を設定 |
| | 行カード | `#photoImportRows` | 下表 |
| | 登録確定 | `#photoImportRegisterButton` | 「照合済み」かつチェック済みの行数を表示。0 件・処理中は無効 |
| 結果 | 結果表示 | `#photoImportResult` | 成功／重複スキップ／失敗の件数と明細、完結済に更新した作品 |

行カードの項目:

| 項目 | 内容 |
|---|---|
| チェック | 登録対象にするか（初期値 ON） |
| 作品 | 作品名入力（datalist）。**完全一致**した作品のみ選択扱い |
| 巻数 | 1 巻のみ（巻数式の範囲・複数指定は入力エラー） |
| Box | セレクト |
| 状態 | 状態バッジ＋説明。「要確認」で巻数ありの場合は [OK] ボタン |
| 読み取り情報 | 写真番号リンク（拡大表示）、読み取った作品名・巻数、候補（2 件以上の場合）、AI の補足 |
| 作品を追加 | 作品名（読み取り結果を初期値）、既存シリーズ／新規シリーズ（作品名を初期値）、種別、完結状態 → [追加して選択] |
| 最終巻 | ON で登録時に作品を `完結済` に更新。作品未選択時は非表示、既に完結済の作品は「完結済の作品」と表示し操作不可 |

#### 行の状態判定（`getPhotoImportStatus`）

上から順に判定します。

| 順 | 条件 | 状態 | 説明 |
|---|---|---|---|
| 1 | 作品未選択 | マスタ未登録 | 作品マスタに無い作品です（自動作成しません） |
| 2 | 巻数が空 | 要確認 | 巻数を入力してください |
| 3 | 巻数が不正、または 2 巻以上 | 入力エラー | 巻数は1つだけ入力してください |
| 4 | 要確認フラグあり | 要確認 | 作品・巻数を確認して「OK」を押してください |
| 5 | Box 未選択 | 入力エラー | Boxを選択してください |
| 6 | 登録済み（`existingKeys`）、またはチェック済みの前の行と同じ作品・巻 | 重複 | 同じ作品・巻数が登録済みです |
| 7 | 上記以外 | 照合済み | 登録可能 |

要確認フラグは、照合結果が `exact` 以外、または AI が `uncertain` を返した行で ON になります。作品・巻数を編集するか [OK] で OFF になります。

#### 作品追加後の動き

追加した作品を当該行に設定し、**同じ読み取り作品名で作品未選択の他の行**にも同じ作品を設定します（他の行は AI が `uncertain` の場合のみ要確認）。各画面の選択肢も再構築します（`refreshMasterData`）。

#### 登録確定後の動き

- 登録できた行は一覧から消し、重複と判定された行は登録済みとして扱います。
- 対応が必要な行（チェック済みで重複以外）が残っていなければ、写真と一覧をクリアします。
- 1 件以上登録できた場合は、最近追加・サマリー・書籍一覧を再読込します。
