# 02. データ設計

## 2.1 データストア

スクリプトにバインドされた Google スプレッドシートの以下のシートを使用します。
シート名はコード上で定数 `SHEETS`（`server/Commons.js`）として定義されています。

| 定数 | シート名 | 内容 |
|---|---|---|
| `SHEETS.LIBRARY` | `M_Library` | 所持書籍（1 巻 = 1 行） |
| `SHEETS.TITLE` | `M_Title` | 作品マスタ |
| `SHEETS.SERIES` | `M_Series` | シリーズマスタ |
| `SHEETS.BOX` | `M_Box` | 保管 Box マスタ |
| `SHEETS.WISH` | `M_Wish` | 欲しい巻リスト（**初回利用時に自動作成**） |
| `SHEETS.ANIME` | `M_Anime` | アニメ作品（**初回登録時に自動作成**） |
| `SHEETS.ANIME_SEASON` | `M_AnimeSeason` | アニメの期（TV の各期・OVA・劇場版。**初回登録時に自動作成**） |
| `SHEETS.ANIME_WATCH` | `M_AnimeWatch` | アニメの視聴状況（期と 1 対 1。**初回登録時に自動作成**） |
| `SHEETS.RELEASE` | `M_Release` | 連載中の漫画・ラノベの、所持巻より先の巻と発売日（楽天ブックスから取得。**初回取得時に自動作成**） |
| `SHEETS.RELEASE_CHECK` | `M_ReleaseCheck` | 発売情報の作品ごとの取得状況（**初回取得時に自動作成**） |
| `SHEETS.READ` | `M_Read` | 書籍の読書状況（**初回登録・変更時に自動作成**。行のない書籍は読了） |
| `SHEETS.RECOMMEND` | `M_Recommend` | おすすめの漫画（AI の挙げた作品と、気になる・興味なしの反応。**初回の作成時に自動作成**） |
| `SHEETS.JUMP_CHECK` | `M_JumpCheck` | ジャンプ作品の印（気になる・興味なし・持っている。**初回に印を付けたときに自動作成**） |

共通ルール:

- **1 行目はヘッダー行**、データは 2 行目以降（`getData(sheetName, startRow = 2)`）。
- **1 列目が主キー（ID）**。行の特定は 1 列目の文字列一致で行う（`updateRowById`）。
- 削除は行の物理削除です。書籍（`deleteLibraryMaster`）・アニメの期（`deleteAnimeSeason`）に加え、作品・シリーズ・Box（`deleteTitleMaster` / `deleteSeriesMaster` / `deleteBoxMaster`）も削除できます。**ほかのシートから使われている作品・シリーズ・Box は削除できません**（作品は `M_Library`、シリーズは `M_Title`・`M_Anime`、Box は `M_Library` に行があるとき）。書籍のない作品を削除すると、その作品の `M_Wish`・`M_Release`・`M_ReleaseCheck` の行も消します。
- 作品・シリーズの最大 ID の行を削除すると、ID 採番（最大 ID + 1）で次の登録に同じ ID が再利用されます。削除できるのは参照のない行だけなので、前の作品・シリーズのデータが新しい行に紐付くことはありません。
- 書籍の最終行を削除すると、ID 採番（最終行 + 1）により次の登録で同じ LibraryID が再利用されます（`M_Read` の行は書籍の削除と同時に消すため、再利用された ID に前の本の読書状況は残らない）。

## 2.2 ER 図

```
M_Series 1 ──── 0..* M_Title 1 ──── 0..* M_Library *..1 ──── 1 M_Box
 (SeriesID)          (SeriesID)  (TitleID)      (TitleID / BoxID)    (BoxID)
```

アニメ（シリーズは書籍と共通の `M_Series`）:

```
M_Series 1 ──── 0..* M_Anime 1 ──── 0..* M_AnimeSeason 1 ──── 0..1 M_AnimeWatch
 (SeriesID)          (SeriesID)  (AnimeID)      (AnimeID)  (SeasonID)      (SeasonID)
```

- 作品はシリーズに所属します（シリーズ未設定も許容：サーバー側では空文字可）。
- 書籍は作品と Box を参照します。
- 外部キー制約はありません。参照先が存在しない場合、表示名は空文字になります。

## 2.3 シート定義

### 2.3.1 M_Library（書籍）

| 列 | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| A (1) | LibraryID | 文字列 | ○ | `L` + 6 桁連番（例 `L000123`） |
| B (2) | TitleID | 文字列 | ○ | `M_Title.TitleID` |
| C (3) | BoxID | 文字列 | ○ | `M_Box.BoxID` |
| D (4) | 巻数 | 文字列 | ○ | `1`, `12` などの数値文字列のほか、`上`, `外伝` などの任意文字列も可 |
| E (5) | 追加日 | 日付 | ○ | 登録時に `Date`（その日の 0:00、`getToday()`）を書き込み。読み出し時は `formatDateCell` で `yyyy/MM/dd` に整形（過去に文字列で保存された値はそのまま表示） |

一意制約（アプリ側でチェック）: **(TitleID, 巻数) の組み合わせが重複しないこと**。

### 2.3.2 M_Title（作品）

| 列 | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| A (1) | TitleID | 文字列 | ○ | `T` + 6 桁連番 |
| B (2) | 作品名 | 文字列 | ○ | |
| C (3) | SeriesID | 文字列 | — | `M_Series.SeriesID`（画面からの登録では必須） |
| D (4) | 種別 | 文字列 | — | `漫画` / `ラノベ`。サマリーの種別別集計・作品一覧の絞り込みに使用 |
| E (5) | 完結状態 | 文字列 | — | `連載中` / `完結済` / `未完結`（画面の選択肢）。写真から登録で「最終巻」指定した巻が登録されると `完結済` に自動更新 |
| F (6) | 予備 | 数値 | — | 登録時に `0` 固定。現在用途なし |
| G (7) | 作者 | 文字列 | — | 複数なら `/` 区切り（楽天ブックスの作者欄と同じ。例 `大場 つぐみ/小畑 健`）。手入力では `原作:` などの役割を書いてもよい（照合では外す）。作品の追加時・一括補完で楽天ブックスから入れる（`TitleAuthorService.js`） |
| H (8) | 出版社 | 文字列 | — | 楽天ブックスの出版社（`publisherName`）または手入力 |
| I (9) | 作者の取得日 | 日付 | — | 楽天ブックスから作者を取りに行った日時（見つからなくても入れる）。一括補完はこれが空の作品だけを対象にする |

G〜I 列は後から足した列で、既存の行は空のまま（見出しは書き込むときに `ensureTitleAuthorHeaders` で入れる）。列の並びは変えません。

### 2.3.3 M_Series（シリーズ）

| 列 | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| A (1) | SeriesID | 文字列 | ○ | `S` + 6 桁連番 |
| B (2) | シリーズ名 | 文字列 | ○ | |

### 2.3.4 M_Box（保管 Box）

| 列 | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| A (1) | BoxID | 文字列 | ○ | **利用者が任意に入力**（自動採番なし）。重複不可 |
| B (2) | 保管場所 | 文字列 | ○ | |

### 2.3.5 M_Wish（欲しい巻）

`getWishSheet()`（`server/WishService.js`）がシートの有無を確認し、なければヘッダー行（1 行目、固定表示）付きで作成します。

| 列 | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| A (1) | WishID | 文字列 | ○ | `W` + 6 桁連番 |
| B (2) | TitleID | 文字列 | ○ | `M_Title.TitleID` |
| C (3) | 巻数 | 文字列 | ○ | 1 行 1 巻（`M_Library` と同じ表記） |
| D (4) | メモ | 文字列 | — | 任意 |
| E (5) | 追加日 | 日付 | ○ | `Date`（`getToday()`）を書き込み |

一意制約（アプリ側でチェック）: (TitleID, 巻数) の重複なし。`M_Library` に登録済みの巻は追加しません。書籍を登録すると（`addNewVolumeWeb` / `bulkAddLibraryFromPhoto`）同じ (TitleID, 巻数) の行は自動で削除されます。

### 2.3.6 M_Anime（アニメ作品）

アニメの 3 シートは `getAnimeSheet()` / `ensureAnimeSheets()`（`server/AnimeService.js`）が、なければヘッダー行（固定表示）付きで作成します。

| 列 | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| A (1) | AnimeID | 文字列 | ○ | `A` + 6 桁連番 |
| B (2) | 作品名 | 文字列 | ○ | 重複不可（`findDuplicateName` で正規化して比較） |
| C (3) | SeriesID | 文字列 | — | `M_Series.SeriesID`（**書籍と共通**） |

### 2.3.7 M_AnimeSeason（アニメの期）

| 列 | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| A (1) | SeasonID | 文字列 | ○ | `AS` + 6 桁連番 |
| B (2) | AnimeID | 文字列 | ○ | `M_Anime.AnimeID` |
| C (3) | 期名 | 文字列 | ○ | 例 `オーバーロード Ⅱ`、`劇場版〇〇`。同じ作品内で重複不可（正規化して比較） |
| D (4) | 種別 | 文字列 | — | `TV` / `OVA` / `劇場版` / `その他` |

### 2.3.8 M_AnimeWatch（アニメの視聴状況）

期 1 件につき最大 1 行（1 列目の SeasonID で更新、なければ追加。`writeAnimeWatch`）。

| 列 | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| A (1) | SeasonID | 文字列 | ○ | `M_AnimeSeason.SeasonID` |
| B (2) | 視聴済話数 | 数値 | — | 0 以上の整数。空欄可 |
| C (3) | 状況 | 文字列 | — | `視聴予定` / `視聴中` / `視聴済` / `視聴中断` |
| D (4) | 更新日 | 日付 | ○ | 最後に話数・状況を書き込んだ日（`getToday()`） |

期を削除すると（`deleteAnimeSeason`）視聴状況の行も削除します。作品・シリーズは残ります。

### 2.3.9 M_Release（発売情報）

`server/ReleaseService.js` が楽天ブックスから取得するたびに作り直すキャッシュです（手で編集しない）。取得時点の所持巻（数字の巻の最大値）より大きい巻を 1 巻 1 行で保存します。取り直した作品の行は差し替え、連載中でなくなった作品の行は消します。所持済みになった巻は画面表示時に除きます。

| 列 | 項目 | 型 | 説明 |
|---|---|---|---|
| A (1) | TitleID | 文字列 | `M_Title.TitleID` |
| B (2) | 巻数 | 文字列 | 数字の巻（`M_Library` と同じ表記で照合） |
| C (3) | 版 | 文字列 | 特装版などの表記（通常版は空）。同じ巻は通常版を優先して 1 行 |
| D (4) | 書名 | 文字列 | 楽天の商品名 |
| E (5) | ISBN | 文字列 | |
| F (6) | 発売日 | 文字列 | 楽天の表記のまま（`2026年11月04日` / `2026年11月下旬` / `2026年12月頃` など）。並べ替え・発売済みの判定は表示時に `parseRakutenSalesDate` で行う。`2026年10月02日` のように日付まであるものはスプレッドシートが日付型に変えるため、読み出し時に `toSalesDateText` で `yyyy年MM月dd日` に戻す（`M_ReleaseCheck` の最新巻の発売日も同じ） |
| G (7) | URL | 文字列 | 楽天ブックスの商品ページ |
| H (8) | 取得日 | 日付 | 取得した日時 |

### 2.3.10 M_ReleaseCheck（発売情報の取得状況）

連載中の漫画・ラノベ 1 作品につき最大 1 行。取り直す作品の選択（取得日時の古い順）と「見つからなかった作品」「完結済みかも」の表示に使います。

| 列 | 項目 | 型 | 説明 |
|---|---|---|---|
| A (1) | TitleID | 文字列 | `M_Title.TitleID` |
| B (2) | 取得日時 | 日付 | |
| C (3) | 結果 | 文字列 | `取得済` / `該当なし`（巻と読める商品がない）/ `エラー`（通信・API のエラー。前回の `M_Release` の行は残す） |
| D (4) | 楽天の最新巻 | 数値 | 楽天で一番大きい巻 |
| E (5) | 最新巻の発売日 | 文字列 | 楽天の表記のまま |
| F (6) | 完結済みかも | 真偽値 | 未発売の巻がなく、最新巻が 1 年以上前 |
| G (7) | メッセージ | 文字列 | 該当なし・エラーの内容 |

### 2.3.11 M_Read（書籍の読書状況）

`getReadSheet()`（`server/ReadService.js`）がシートの有無を確認し、なければヘッダー行（1 行目、固定表示）付きで作成します。`M_Library` の列順を変えないよう、書籍 1 冊につき最大 1 行を別シートに持ちます。

| 列 | 項目 | 型 | 説明 |
|---|---|---|---|
| A (1) | LibraryID | 文字列 | `M_Library.LibraryID` |
| B (2) | 状況 | 文字列 | `未読` / `読書中` / `読了`（`READ_STATUSES`） |
| C (3) | 更新日 | 日付 | `getToday()` |

- **行のない書籍は `読了`**（`READ_DEFAULT_STATUS`）。読書状況の記録を始める前（2026-11-01 より前）に登録した本は読了として扱う。
- 新しく登録した本（`addNewVolumeWeb` / `bulkAddLibraryFromPhoto`）は `未読` の行を作る（写真から登録で「読了として登録」にしたときは `読了`）。
- 書籍を削除すると（`deleteLibraryMaster`）その行も消す。

### 2.3.12 M_Recommend（おすすめの漫画）

`getRecommendSheet()`（`server/RecommendService.js`）が、なければヘッダー行（固定表示）付きで作成します。

| 列 | 項目 | 型 | 説明 |
|---|---|---|---|
| A (1) | RecommendID | 文字列 | `R` + 6 桁連番 |
| B (2) | 作品名 | 文字列 | AI の挙げた作品名（AI の表記のまま） |
| C (3) | 作者 | 文字列 | 楽天の `author`（見つからなければ AI の回答） |
| D (4) | おすすめの理由 | 文字列 | 1〜2 文 |
| E (5) | 似ている作品 | 文字列 | 根拠にした手持ちの作品名（「、」区切り。最大 3 件） |
| F (6) | 状態 | 文字列 | `候補` / `気になる` / `興味なし`（`RECOMMEND_STATUSES`） |
| G (7) | 楽天URL | 文字列 | 1 巻（なければいちばん古い商品）の商品ページ。未確認なら空 |
| H (8) | 画像URL | 文字列 | 楽天の表紙画像。未確認なら空 |
| I (9) | 確認 | 文字列 | `確認済`（楽天で見つかった）/ `未確認`（楽天の認証情報なし・通信エラー） |
| J (10) | 作成日 | 日付 | 作成した日時 |

- [おすすめを探す] で新しいおすすめが見つかると、**状態が `候補` の行を消して**追加します。`気になる` / `興味なし` の行は残し、次回の AI への指示に使います（新しいおすすめが 0 件なら前回の候補も残す）。
- 手持ちの作品（`M_Title`）と同じ作品（あとで買って登録したもの）は、表示時に照合して画面に出しません（行は残す）。

### 2.3.13 M_JumpCheck（ジャンプ作品の印）

`getJumpCheckSheet()`（`server/JumpService.js`）が、なければヘッダー行（固定表示）付きで作成します。作品そのものはシートではなく定数 `JUMP_TITLES`（`server/JumpTitles.js`）に持ちます。

| 列 | 項目 | 型 | 説明 |
|---|---|---|---|
| A (1) | No | 文字列 | `JUMP_TITLES` の No（Wikipedia「週刊少年ジャンプ連載作品の一覧」の通し番号） |
| B (2) | 作品名 | 文字列 | 印を付けたときの作品名（シートを見たときの目印。処理では使わない） |
| C (3) | 状態 | 文字列 | `気になる` / `興味なし` / `持っている`（`JUMP_STATUSES`） |
| D (4) | 更新日 | 日付 | `getToday()` |

- 1 作品 1 行。印を付け直すと行を消して書き直し、印を外すと行を消す。
- `JUMP_TITLES` の 1 行は `[No, 作品名, 作者（作画 / 原作など）, 開始（年.号）, 終了（年.号。連載中は空）]`。対象は紙版で 2000 年以降に連載が始まった作品（電子版限定は除く）。2026 年 41 号時点の一覧から作成し、新しく始まった・終わった作品は手で更新する。

## 2.4 ID 採番

`M_Library` / `M_Title` / `M_Series` / `M_Wish` / `M_Anime` / `M_AnimeSeason` / `M_Recommend` は `generateNextId(prefix, lastId)`（`server/Commons.js`）で採番します。

1. `getMaxId(sheetName)` で**1 列目のうち末尾の数字が最大の ID** を取得（データなしの場合 `null`）。シートを並べ替えても重複しません
2. その値から `prefix` を除去して整数化し、+1
3. `prefix` + 6 桁ゼロ埋めで返却（解析不能・`null` の場合は `000001`）

| シート | prefix | 例 |
|---|---|---|
| M_Library | `L` | `L000001` |
| M_Title | `T` | `T000001` |
| M_Series | `S` | `S000001` |
| M_Wish | `W` | `W000001` |
| M_Anime | `A` | `A000001` |
| M_AnimeSeason | `AS` | `AS000001` |
| M_Recommend | `R` | `R000001` |

前提・制約:

- 最大 ID の行を削除すると、次の登録で同じ ID が再利用されます（ID は他シートから参照されない LibraryID・WishID・RecommendID では影響なし）。
- 追加・更新・削除はすべてスクリプトロックで排他するため、同時登録でも同一 ID は発行されません。
- シリーズ名は重複不可（全角半角・大文字小文字・ひらがな/カタカナ・空白記号の違いを無視して比較。`findDuplicateName`）。
- 作品は**作品名と種別の組み合わせ**が重複不可（同じ作品名でも漫画とラノベは別作品として登録できる。`findDuplicateTitle`）。同名の作品は画面の選択肢で「作品名（種別）」と表示して区別します（`buildTitleLabelMap`）。
- 6 桁を超える（1,000,000 件以上）と桁あふれで下 6 桁に切り詰められます。

## 2.5 画面とデータのマッピング（主要項目）

| 画面上の表示 | 取得元 |
|---|---|
| 作品名（書籍一覧など） | `M_Library.TitleID` → `M_Title.作品名` |
| Box（書籍一覧など） | `M_Library.BoxID` → `M_Box.保管場所` |
| シリーズ（作品一覧など） | `M_Title.SeriesID` → `M_Series.シリーズ名` |
| 所持巻数（シリーズの詳細） | `M_Library` を TitleID ごとに件数集計 |
| 漫画/ラノベ所蔵冊数 | `M_Library` × `M_Title.種別` で件数集計 |
| 積読・読書状況（サマリー・書籍一覧・作品の詳細・ホーム） | `M_Library.LibraryID` → `M_Read.状況`（行がなければ読了） |
| アニメの作品名・シリーズ（期の一覧） | `M_AnimeSeason.AnimeID` → `M_Anime.作品名` → `M_Anime.SeriesID` → `M_Series.シリーズ名` |
| アニメの話数・状況 | `M_AnimeSeason.SeasonID` → `M_AnimeWatch` |
| おすすめ・気になる（おすすめ画面） | `M_Recommend`（`M_Title` と同じ作品名のものは除く）。「似ている手持ち」のリンクは作品名で `M_Title` と照合 |
| 持っている・持っていない（ジャンプ作品画面） | `JUMP_TITLES` の作品名を `M_Title`（ラノベを除く）の作品名と照合し、`M_Library` の冊数が 1 冊以上なら持っている。`M_JumpCheck` の `持っている` も持っている扱い |
| 発売予定・発売済未所持（発売予定画面） | `M_Release`（`M_Library` に同じ (TitleID, 巻数) があれば除く。欲しい巻は `M_Wish` と照合）→ `M_Title.作品名` |
