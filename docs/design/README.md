# 設計書（にんじん図書館 / 漫画ライブラリ管理）

本ディレクトリは、現行実装（`src/` 配下）から起こした設計書です。
ソースコードと同じリポジトリで管理し、**実装を変更したら同じコミット（または同じ PR）で設計書も更新する**ことを原則とします。

## 運用ルール

- 記載の基準は **`src/` 配下のソース**です。`build/` はビルド成果物のため設計の根拠にしません。
- 設計書中のソース参照は `src/` からの相対パス（例: `server/LibraryService.js`）で記載します。
- 実装と設計書に差異を見つけた場合は、どちらが正しいかを判断のうえ、
  - 実装が正 → 設計書を修正
  - 設計書が正 → 実装を修正し、[06_known_issues.md](06_known_issues.md) から該当項目を削除（機能拡張候補（E）は「状況」を対応済にする）
- 機能追加・仕様変更時は [07_change_history.md](07_change_history.md) に 1 行追記します。

## 用語

| 用語 | 意味 |
|---|---|
| 書籍 / ライブラリ | 所持している 1 冊（1 巻）単位のデータ。シート `M_Library` の 1 行 |
| 作品 / タイトル | 巻をまとめた作品単位のデータ。シート `M_Title` の 1 行 |
| シリーズ | 複数作品（本編・スピンオフ等）をまとめる単位。シート `M_Series` の 1 行 |
| Box / 箱 | 物理的な保管場所（収納箱）。シート `M_Box` の 1 行 |
| 種別 | 作品の分類。現在は `漫画` / `ラノベ`（アニメの期は `TV` / `OVA` / `劇場版` / `その他`） |
| アニメ作品 | アニメの作品単位のデータ（例: オーバーロード）。シート `M_Anime` の 1 行。シリーズは書籍と共通 |
| 期 | アニメ作品の TV の各期・OVA・劇場版など 1 本単位のデータ。シート `M_AnimeSeason` の 1 行。視聴済話数・状況は `M_AnimeWatch` |
| GAS | Google Apps Script |
